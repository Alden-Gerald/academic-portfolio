University Projects

Coursework from my Information Systems degree. Each card says what I did and what the project delivered, and links to the public repository.

  • Cloud Computing & AWS

    AWS Cloud Storage Strategy

    An architecture case study that matches education-platform workloads to storage services by weighing latency, scale, durability, access, security, and cost.

    Role
    Individual case study.
    Decision
    One storage service per workload instead of one for everything, held together by IAM, lifecycle policies, and naming conventions.
    Result
    A recommendation per workload, with an architecture diagram.
    • EBS
    • S3
    • CloudFront
    • EFS
    • S3 Glacier
    • IAM

  • System Analysis & Design

    Hampiness System Design

    A system-design study that moves from requirements and root-cause analysis to process models, interactions, and a proposed three-tier marketplace architecture.

    Role
    Team project. I covered system analysis and design: requirements, process and object modeling, and architecture.
    Decision
    A three-tier architecture, to keep layers separate for maintainability, security, and future scale.
    Result
    Fishbone analysis, DFDs, use cases, and class, sequence, and activity diagrams.
    • DFD
    • UML
    • Fishbone analysis
    • Three-tier architecture
    View repository
  • Database & Desktop

    Student Registration

    A JavaFX desktop app for creating and updating student registration records, with validation and clear confirmation feedback.

    Decision
    A separate DAO layer keeps interface code apart from database access. Database credentials come from environment variables.
    Result
    Full create, read, update, and clear flow over MySQL, with a schema file for setup. The public copy holds no real student records.
    • Java 17
    • JavaFX 21
    • MySQL
    • JDBC
    • DAO
    View repository
  • Web Development & Database

    ThriftVibe Marketplace

    A database-backed thrift marketplace prototype that brings buyer, seller, and administrator journeys together in one web application.

    Role
    Team project. I turned marketplace flows into working pages and connected them to server-side logic and MySQL.
    Decision
    All queries go through PDO prepared statements. The public copy ships the schema only, with no credentials or user data.
    Result
    Three role-based workflows: browsing through checkout, seller tools, and admin moderation.
    • PHP 8+
    • MySQL
    • HTML
    • CSS
    • JavaScript
    • PDO

Local AI & Developer Tools

Lumina

A private, local-first workspace for chat, study, document work, and bounded coding tasks, powered by local models through Ollama. It has four workspaces: Chat, Code, Files, and Control.

Role
Sole author, from design to testing.
Decision
Coding tasks run in disposable Git workspaces. Changes are validated first, then applied through a guarded step that verifies and backs up the source files.
Result
Works with PDF, Office, CSV, and image attachments, and ships with a Python unit test suite.
  • Python
  • Ollama
  • Git workspaces
  • MCP
  • Web interface
  • unittest
